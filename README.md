Repositório dedicado aos meus estudos em **Java e Programação Orientada a Objetos (POO)**, com exercícios práticos, resolução de problemas e exemplos desenvolvidos ao longo da minha jornada de aprendizado.

O objetivo é consolidar os fundamentos da linguagem Java, desenvolver o raciocínio lógico e construir uma base sólida para o desenvolvimento de aplicações.

## 📚 Conteúdos estudados

Os exercícios estão organizados em diretórios de acordo com os assuntos praticados.

- **Sintaxe básica:** estrutura de um programa Java e comandos fundamentais.
- **Variáveis e tipos de dados:** declaração, inicialização e manipulação de variáveis.
- **Operadores aritméticos:** cálculos e expressões matemáticas.
- **Operadores lógicos e relacionais:** comparação de valores e construção de condições.
- **Estruturas condicionais:** tomada de decisões com base em condições.
- **Estruturas de repetição:** utilização de `while` e `do while`.
- **Arrays:** armazenamento e manipulação de conjuntos de valores.
- **Resolução de problemas:** exercícios envolvendo números, idades, estoque, retângulos e outras situações práticas.
- **Programação Orientada a Objetos (POO):** estudos relacionados aos fundamentos da orientação a objetos.

## 🚀 Como executar os exercícios

### 1. Clone o repositório

Abra o terminal e execute:

```bash
git clone https://github.com/DavidMauricioDev/EstudandoJava.git
```

### 2. Entre na pasta do projeto

```bash
cd EstudandoJava
```

### 3. Abra o projeto

Abra a pasta em sua IDE Java preferida ou no editor de código que utiliza.

### 4. Execute um exercício

Localize o arquivo `.java` correspondente ao exercício desejado e execute sua classe principal.

Se o arquivo possuir um método `main`, também é possível compilar e executar pelo terminal:

```bash
javac NomeDaClasse.java
java NomeDaClasse
```

**Observação:** substitua `NomeDaClasse` pelo nome real da classe, sem a extensão `.java`. Se o exercício utilizar pacotes ou depender de outras classes, compile e execute a partir da estrutura correta do projeto.
